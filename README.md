# Student Attendance Management System

## Overview
The **Attendance Management System** is a web-based application designed to track and manage student attendance efficiently. It provides an interactive interface where users can mark attendance, view records, and generate reports. The system is built using **HTML, CSS, and JavaScript** for a smooth and responsive user experience.

## Technologies Used
- **HTML** – Structure and layout of the system.
- **CSS** – Styling and responsiveness.
- **JavaScript** – Logic for attendance management and data handling.

## Usage
1. **Open the Application** – Launch `index.html` in a browser.
2. **Login** – Enter the username name and password.
3. **Add Student Details** – Add/Delete the Student details such as Name,No.,City,Roll.no.
4. **Attendance Mark** – Mark the Attendance such as Present/Absent.
